# Rust owns data and logic; the UI is a thin typed view

All data, validation and business rules live in Rust (`crates/core` and Module crates). The Svelte UI renders state, collects input and calls typed commands whose bindings are generated by tauri-specta. This keeps one source of truth for rules across desktop and Android, makes the rules testable without a UI, and stops validation from drifting between two languages.
